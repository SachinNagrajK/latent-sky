IMPLEMENTED SUPABASE CONTRACT

Supabase creates an anonymous guest identity automatically; existing sessions are preserved. The browser calls the authenticated enqueue_job RPC directly. The optional submit-run Edge Function source is supplied but not deployed. The RPC accepts only fixed presets, bounds stretch parameters, limits active runs, and returns the existing job for an idempotent retry. A local Python worker claims one queued job using SKIP LOCKED and a timed lease, heartbeats, uploads outputs, then commits only if its lease remains valid. Failed or expired work has at most three total attempts.

Private output paths start with the owner ID in the astronomy bucket. The browser obtains expiring signed links. RLS policies restrict job-associated reads to the owner. Browser roles cannot write trusted detections, quality snapshots, or job state. The backend service credential belongs only in the worker environment. The supplied migrations define Realtime for jobs/reviews and a five-minute Cron health scheduler. Both migrations are applied to the live project. Successful live runs verified the core job, worker, storage and result flow.

DATA QUALITY APPROACH

Layer 1 — Input integrity. Download bounded fixed archive requests; verify checksums, cube layout, expected g/r/z order, finite celestial WCS, and usable nonzero coverage. Preserve floating-point science arrays. Keep original source URLs and retrieval dates. Reject bad metadata before trusted outputs. The archive cutouts do not provide a physical BUNIT or a reliable coadd acquisition date; record that absence instead of inventing values.

Layer 2 — Scientific evidence. Mosaic reprojection uses valid pixel overlap weights. Overlapping existing survey stacks do not create independent extra exposure depth. Source extraction operates on the original r-band data using a local SEP background and five-sigma threshold. Three-pixel aperture flux errors omit correlated-noise correction. Edges, the central galaxy halo, and SEP flags are marked for artifact review. No extended-source label is asserted without a measured PSF. Full survey bit masks are not yet integrated.

Layer 3 — Catalog comparison. Match measured positions to the pinned reference subset with a two-arcsecond tolerance and retain the separation and catalog ID. Nineteen of twenty detections have positional matches, including some artifact-flagged measurements. A missing match is not proof of a new object, a galaxy, or Coma membership.

Layer 4 — Database protection. Curated coordinate and coverage constraints, RLS, owner-scoped private Storage, idempotency, retry limits, and lease-token checks support trustworthy state. These require live integration testing before being claimed as verified production protection.

Layer 5 — Separately attributed Sodabase evidence. Watch staging, observations, detections, and events in the intended project. Record actual rule responses with provider='sodabase'; local checks use provider='app'. Preserve unknown/error/scanning states and provider timestamps. The current generic adapter stores an unparsed successful response as “evidence received”; it does not invent a pass verdict or violation count. Bind and verify exact rule scope and response fields during connection.
